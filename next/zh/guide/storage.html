存储管理 ​

服务器模式下，项目的源文件、译文与导出产物都保存在对象存储里：默认使用服务器本地磁盘，也可以接入你自己的 S3 兼容对象存储。本页讲两件事：普通用户如何为项目选择与迁移存储、管理源文件版本；管理员如何配置站点存储、审核自有存储与设置存储政策。

适用范围

存储能力随服务器模式（含 Docker）提供。本地模式的数据直接落在本机数据目录，无需（也没有）存储配置界面；部署侧的 server.storage.* 配置见 配置文件与环境变量。

两种存储方式 ​

新建项目时选定的存储空间决定文件保存在哪里：

方式文件在哪适合
站点托管管理员在存储管理页配置的站点空间（本地磁盘目录或 S3）默认方式，开箱即用
自有存储（BYOS）用户 / 组织自行接入的 S3 兼容存储连接想把文件留在自己的 bucket 里

站点采用哪种政策由管理员设定（见下文 站点存储政策），可选仅站点托管、两者皆可或强制自有存储。

新建项目：选择存储空间 ​

服务器模式下创建项目时，界面会要求明确选择一个存储空间（不会自动替你选第一项）：

  • 无可用目标时会提示「服务尚未提供可用空间及默认选择，暂不能创建项目」，此时联系管理员配置存储
  • 每个候选空间都会标注不可选原因（如「当前政策不接受此空间」「存储服务正在维护」「空间额度不足」）

项目存储：绑定与迁移 ​

项目工作区的 项目存储 页签展示当前绑定：

  • 当前空间 — 项目文件所在空间、存储代次与站点存储维护状态
  • 重新绑定 — 空项目可直接换绑其他空间
  • 迁移已有数据 — 非空项目支持把全部文件迁移到另一空间（复制 → 验证 → 切换 → 清理）；迁移期间限制新增持久内容，迁移过程遵循站点维护状态

迁移是持久化的存储任务，可在 任务中心 追踪进度；失败可重试，已完成阶段不重跑。

源文件与固定交付 ​

资源级抽屉「源文件与固定交付」提供版本化的源文件管理：

  • 版本历史 — 每个版本记录文件格式、解析器版本、原件大小与 SHA-256，可区分当前版本与历史版本
  • 更新源文件 — 预览-确认式替换（见下节）
  • 同字节修复 — 原件损坏或误改时，上传与原版本逐字节一致的文件修复历史版本；不切换工作区、不改动译文
  • 固定交付 — 把当前译文保存为交付版本，之后源文件再怎么更新都不影响它；需要时可用「使用旧快照重建」回滚，也支持下载与删除

更新源文件 ​

替换已有资源的源文件走预览-确认流程，不会静默覆盖：

  1. 选择新源文件
  2. 点 预览变化 — 查看新增段落、原文变更段落、删除段落与未变化段落的统计
  3. 逐个候选 确认更新 — 每次更新生成可追踪的存储任务

旧版本没有可信基线时

若旧版本缺少可信的原件基线，界面会提供 下载旧成果 JSON 快照，先留底再更新。

会话与草稿保护 ​

存储操作与翻译编辑共用一套保护：

  • 有未保存的译文或备注时发起源文件更新等操作，会弹出「有未保存的译文或备注」对话框，可选 保存并继续 / 放弃并继续 / 取消
  • 登录态或资源归属变化后，未完成的操作会被拦截；请求结果未知时提示「请求结果待确认」并引导查看原任务，避免重复提交

存储任务 ​

任务中心的任务类型除翻译、术语同步外，还包括文件存储任务（文件上传 / 源文件更新 / 同字节修复）。详情抽屉展示处理阶段（等待执行 → 候选已准备 → 复制文件 → 验证文件 → 切换存储绑定 → 清理旧文件 → 处理完成）与空间清理状态，并提供「前往项目存储」「恢复原任务」入口。

管理员：存储管理页 ​

管理员后台的 存储管理 页（/admin/storage）分三块：

总览与诊断 ​

  • 容量明细 — 各空间的「登记占用 / 空间配额」
  • 只读诊断 — 缺失对象、损坏对象数、恢复积压、最早未完成意图等健康指标

存储连接与空间 ​

操作说明
新建连接 / 新建空间连接指向一个 S3 兼容端点，空间是连接下带容量配额的 bucket 前缀
更新授权 / 撤销授权管理连接的访问凭据；密钥只写不回显
只读检测 / 写入检测验证连接可用性；写入检测会创建并清理探测对象
启用 / 禁用连接、设为只读 / 恢复可写控制空间可用状态

用户与组织也可在各自页面管理自有存储连接（个人 / 组织级），管理员可在此看到站点级连接。

站点存储政策 ​

设定全站的存储方式：

政策模式含义
仅站点托管所有项目只能用站点空间
站点托管或自有存储用户可为项目选择站点空间或自有存储
必须使用自有存储项目必须绑定用户 / 组织自己的存储

政策还包含默认选择与逻辑容量上限；修改政策时会与未保存的项目数据做冲突核对。政策生效由服务端逐操作准入（能力发现接口向下发放可用操作快照），被拒绝的操作会给出稳定原因（如存储维护中、连接已禁用、空间只读、未授权）。

维护状态 ​

站点进入存储维护态时，所有存储写入被拒绝（任务中心会显示对应状态）。除管理员手动设置外，启动时检测到未完成的旧版数据迁移任务也会自动进入维护态，处理完再恢复。

旧数据迁移与备份（独立工具） ​

从旧版本升级（把 data/jobs 下的文件搬入新存储）或做灾备时，使用独立命令行工具 linguaflow-storage-migrate：支持清点、演练、正式迁移、断点续跑、回滚，以及离线一致性备份与恢复校验。用法见 CLI 命令参考 · 存储迁移与备份工具。

迁移前先备份

正式迁移要求同时提供 --offline 与 --backup-confirmed——先完成备份并确认，再执行迁移。
