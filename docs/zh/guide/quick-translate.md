# 即时翻译

不想建项目、不想上传文件，只想把一段文字丢进去看译文？**即时翻译**就是为这个准备的。

它复用项目翻译同一套执行计划、术语表与流水线，但 **单段、临时、不落库**——译文只给你看，关掉页面就没了。

::: tip 和谁有关
- 想快速试一个执行计划 / 提示词 / 模型的效果
- 有一段零散文本要立刻译，不需要存档
- 想在正式建项目前先验证语言方向与术语是否对路
:::

## 在哪里用

| 入口                                | 说明                                                               |
| ----------------------------------- | ------------------------------------------------------------------ |
| **首页 / 开始翻译**（`QuickTranslateWidget`） | 顶部首页即是一个即时翻译卡片，粘贴 → 选计划 → 出结果                |
| **工具 → 即时翻译**（独立页）       | 同样的能力，单独全宽页面，方便长期挂着                              |

两个入口指向同一个能力，只是版式不同。

## 怎么用

1. **粘贴或输入原文** — 单段文本，可含多句
2. **选择语言** — 源语言可留 `auto`（自动检测）；目标语言默认 `zh`，可改
3. **选择执行计划** — 必选；计划决定用哪个后端、几轮翻译、是否带裁决 / 语义质检
4. **（可选）挂项目术语表** — 选一个项目，翻译时自动套用该项目的术语规则与语言配置
5. **（可选）内联术语表** — 当场填几条 `源 → 目标` 临时术语；项目场景下叠加在项目术语表之上
6. **点击翻译**，等待结果

::: warning 译文不落库
即时翻译在内存里跑完即丢。**不会**写入任何项目、资源或段落。要想保留译文，请复制出来，或改用 [项目 / 资源翻译](/zh/guide/projects)。
:::

## 结果展示

翻译完成后，页面会给出：

| 区域             | 内容                                                                 |
| ---------------- | -------------------------------------------------------------------- |
| **译文**         | 目标语言结果；失败时可能为空                                         |
| **质量标记**     | 沿用流水线的规则质检结果（如长度比、源语残留等），与项目翻译一致     |
| **轮次概览**     | 每一轮的模式、后端、状态、耗时。多轮计划会列出多行                   |
| **诊断详情**     | 每批次的 system prompt / user message / 响应原文 / token 用量（隐私裁剪，不含 API Key）|
| **用量**         | API 调用次数、输入 / 输出 token 数                                   |
| **警告**         | 流水线在运行中遇到的非致命提示                                       |

### 轮次状态

| 状态       | 含义                                                                         |
| ---------- | ---------------------------------------------------------------------------- |
| `success`  | 该轮全部完成                                                                 |
| `partial`  | 该轮部分段失败（仍产出可用译文）                                             |
| `failed`   | 该轮失败，没有可用译文                                                       |
| `skipped`  | 该轮因目标段状态不满足 `segment_filter` 被跳过，译文沿用上一轮结果          |

::: info `skipped` 何时出现
单段即时翻译首轮一定会执行；只有 **多轮翻译计划** 的后续轮次才可能 `skipped`——因为目标段只有一条，首轮译完状态变化后，后续轮按过滤策略可能判定「无需再译」。

这与 [单段试译](/zh/guide/translation-config#单段试译) 的多轮过滤语义一致，详见 [流水线与原理 · 多轮试译的过滤语义](/zh/guide/pipeline#多轮试译的过滤语义)。
:::

## 术语表叠加规则

即时翻译可同时使用项目术语表 + 内联术语表：

```
最终生效术语 = 项目术语表（若选了项目）∪ 内联术语表（若填了）
```

内联术语表每条可设：

| 字段             | 默认     | 说明                                   |
| ---------------- | -------- | -------------------------------------- |
| `source`         | （必填） | 源术语                                 |
| `target`         | （必填） | 目标译法                               |
| `case_sensitive` | `false`  | 是否区分大小写                         |
| `forbidden`      | `false`  | 禁译：译文中**不应**出现这个 target    |
| `mandatory`      | `true`   | 强制：命中 source 时必须用这个 target  |
| `notes`          | （可选） | 备注，注入给模型作提示                 |

术语规则的运作方式（命中后做什么、如何触发质检）见 [术语表管理 · 禁译 / 强制](/zh/guide/glossary#禁译-forbidden-与强制-mandatory)。

## 和单段试译、项目翻译的区别

| 维度     | 即时翻译                         | [单段试译](/zh/guide/translation-config#单段试译)        | [项目翻译](/zh/guide/projects)              |
| -------- | -------------------------------- | -------------------------------------------------------- | -------------------------------------------- |
| 入口     | 首页 / 工具页                    | 工作区 → 段落行                                          | 工作区 → 资源 / 作业                         |
| 输入     | 任意粘贴文本                     | 已存在的段落原文（可临时改）                             | 已上传的资源文件                             |
| 数据落库 | ❌ 不落库                        | 只有显式「应用译文」才写回段落                           | 译文写入段落、可审校、可导出                 |
| 术语来源 | 内联 + 可选项目                  | 项目术语表（临时覆盖层）                                 | 项目术语表                                   |
| 适合     | 临时翻译、快速试计划             | 段落级试效果再决定要不要覆盖                             | 正式批量本地化                               |

简单判断：

- **只想译一段、不留底** → 即时翻译
- **已有项目段落、想试某计划对它的效果** → 单段试译
- **要批量、可审校、可导出** → 项目翻译

## 限制

- **单段**：一次翻译一段文本（可含多句）。整篇文档请走项目翻译。
- **并发受限**：即时翻译有独立的并发上限（默认每用户 2、全局 8），见 [配置文件与环境变量 · 即时翻译](/zh/guide/configuration#server-quick-translate-—-即时翻译)。提示「并发已满」时稍后重试即可。
- **超时**：默认单次 5 分钟（与单段试译一致，因含 429 指数退避，单轮 LLM 调用可能较慢）。服务器管理员可在 `server.quick_translate.timeout` / `max_timeout` 调整。
