# 项目管理

项目是组织一次翻译工作的基本单位：语言方向、源文件（资源）、术语表与翻译作业都挂在项目下。

尚未跑通第一次翻译？请先看 [快速开始 · Web](/zh/guide/getting-started)。名词解释见 [核心概念](/zh/guide/concepts)。

## 创建项目

1. 打开 **项目** 页，点击 **新建项目**
2. 填写项目信息：
   - **项目名称** — 用于标识项目（最多 80 个字符）
   - **源语言** — 源文件语言，可用 `auto` 自动识别
   - **目标语言** — 要译成的语言
   - **启用术语表** — 是否在翻译时应用术语规则
3. **选择存储空间**（服务器模式）— 明确选择项目文件保存的空间，系统不会自动替你选；无可用空间或空间不可选时会标注原因（维护中、额度不足等），详见 [存储管理 · 新建项目](/zh/guide/storage#新建项目选择存储空间)
4. 点击 **创建**，再点进项目卡片进入工作区

::: tip 提示
创建后可随时改名称、语言与术语表开关。本地模式下你就是唯一用户，无需关心组织归属。
:::

### 项目归属（服务器模式 · 预览）

::: warning 预览
组织与多用户归属依赖服务器模式，该模式仍在完善。个人本地使用时项目都归属你自己，无需关心组织。
:::

- **个人项目** — 归属当前用户
- **组织项目** — 归属组织，同组织成员按角色协作

服务器模式下，列表页顶部提供**组织作用域切换**（个人 / 各组织），切换后项目、AI 后端、提示词模板、执行配置等资源列表都按所选范围展示。项目编辑抽屉中可将项目复制到你有写权限的组织（**复制到组织**），方便把个人成果沉淀为团队资产。

组织与成员管理见账号设置中心的 **团队** 页：创建 / 编辑组织、按用户名添加成员、调整成员角色（所有者 / 成员）、移除成员或退出组织。

## 项目列表

**项目** 页展示所有项目卡片，支持以下功能：

- **搜索过滤** — 按项目名称搜索
- **术语表状态筛选** — 全部 / 已启用 / 未启用
- **排序** — 按更新时间降序排列
- **整卡进入** — 点击项目卡片任意位置进入工作区；卡片上直接提供 **编辑**、**删除** 操作（删除需二次确认）

::: tip 工作区内也能编辑项目
项目工作区标题旁有编辑入口，可直接修改项目名称、源/目标语言与术语表开关，无需返回项目列表。
:::

## 项目工作区

进入项目后，顶部显示项目基本信息（名称、语言方向、更新时间，标题旁有编辑入口）和统计指标栏：

| 指标       | 说明                 |
| ---------- | -------------------- |
| 资源数     | 项目中的文件总数     |
| 段落数     | 待翻译的内容段总数   |
| 已翻译     | 已完成翻译的段落数   |
| 已审核     | 已通过审核的段落数   |
| 运行中作业 | 正在执行的翻译作业数 |

工作区（浏览态）包含四个标签页：

1. **资源文件** — 文件管理（详见下方），点击资源即可进入编辑视图
2. **任务** — 翻译作业管理（详见下方）
3. **术语表** — 项目术语管理
4. **项目存储** — 当前绑定的存储空间与存储代次，支持空项目重新绑定、已有项目迁移数据（详见 [存储管理 · 项目存储](/zh/guide/storage#项目存储绑定与迁移)）

## 编辑视图

点击任意资源（或其操作菜单的 **查看段落**）即进入独立的**编辑视图**——一个沉浸式的段落工作台，与浏览态的标签页分离：工具栏有 **返回工作台** 按钮，URL 也会带上资源与章节参数，可以直接分享或恢复到某个资源的某个章节。

编辑视图采用**三栏布局**（空间不足时侧栏自动收为抽屉）：

- **左栏 · 章节侧栏**（EPUB 资源）— 列出全部章节标题与逐章进度（已译段数 / 总段数），可切换「全部章节」或具体章节
- **中栏 · 段落列表** — 翻译内容查看与编辑，支持按状态 / 质量问题筛选；段落行操作菜单可发起 [单段试译预览](/zh/guide/translation-config#单段试译) / [单段修订预览](/zh/guide/translation-config#单段修订预览)，满意后再应用译文
- **右栏 · 查找 / 替换面板** — 在整个资源、具体章节或选中段落范围内查找原文 / 译文并跳转定位，展开替换行可对译文批量查找替换（详见 [翻译审校 · 查找与定位](/zh/guide/review#查找与定位) 与 [翻译审校 · 搜索替换](/zh/guide/review#搜索替换)）

段落列表滚动到底自动加载更多，无需手动点击；通过搜索跳转到中间位置后，可继续向上 / 向下加载上下文。

### 章节批量处理

EPUB 资源可在章节侧栏进入**批量处理**模式：全选 / 勾选 / 清空章节后，对所选章节发起**翻译任务**或 **QA 重检**，处理完点 **退出** 离开批量模式。这一入口也从原资源浏览区的 EPUB 章节目录迁到了这里。

## 管理翻译资源

### 上传文件

支持以下方式上传文件：

- **拖拽上传** — 将文件拖拽到上传区域
- **点击上传** — 点击上传按钮，通过系统文件选择器一次选取多个文件
- **批量上传** — 一次最多上传 50 个文件

一次选择多个文件时，会合并为一个**批次任务**：上传面板按批次展示任务，而不是每个文件各占一条；状态摘要与进度按批次内文件数汇总（如「正在上传 3 个文件」），展开面板可见每个批次任务的文件名、所处阶段、上传百分比或错误信息。

::: tip 提示
上传前会自动进行冲突检测。如果同名文件已存在，可选择替换或增量更新。
:::

详见 [格式支持](/zh/guide/formats)。

### 资源管理

上传后的资源可以进行以下操作：

- **查看段落** — 进入编辑视图，浏览与编辑翻译内容
- **更新源文件** — 替换 / 增量更新已有资源，走**预览-确认**流程：先看新增、原文变更、删除与未变化段落的统计，再逐个确认；每次更新生成可追踪的存储任务（详见 [存储管理 · 更新源文件](/zh/guide/storage#更新源文件)）
- **源文件与固定交付** — 查看源文件版本历史（格式、大小、SHA-256），损坏原件可「同字节修复」；可把当前译文「保存为交付」固定下来，源文件再更新也不影响（详见 [存储管理 · 源文件与固定交付](/zh/guide/storage#源文件与固定交付)）- **下载** — 下载原始文件；**下载译文** 把译文写回原格式导出，EPUB 译文下载前会做结构预检，存在结构缺陷时不输出文件，并在对话框中给出缺陷段落编号与原因（见 [翻译审校 · 结构预检](/zh/guide/review#结构预检)）
- **删除** — 删除资源及其所有段落和翻译
- **翻译** — 勾选资源后经浮动操作栏 **处理选中** 启动翻译作业（EPUB 可在编辑视图章节侧栏按章节发起，见上文「章节批量处理」）

### EPUB 特殊支持

EPUB 与其他格式一样，点击资源即直接进入编辑视图；章节导航在编辑视图左侧的**章节侧栏**中，可切换全部 / 单个章节，也可按章节发起翻译任务或 QA 重检（见上文「编辑视图」）。若需统一全书横排/竖排，可使用 Web **工具 → EPUB 横竖排转换**（本机处理、不上传），见 [格式支持 · EPUB](/zh/guide/formats#epub-电子书)。

## 翻译作业

### 创建翻译作业

1. 在项目中选择需要翻译的资源（或资源中的特定段落/章节）
2. 选择翻译执行计划
3. 配置作业参数：
   - **过滤配置** — 控制对已有翻译的处理方式
   - **自动审核** — 翻译完成后是否自动标记为已审核
4. 点击 **开始翻译**

### 过滤配置

创建作业时可配置段落过滤，控制哪些段落需要重新翻译：

| 过滤选项   | 说明                         |
| ---------- | ---------------------------- |
| 跳过已批准 | 跳过已审批通过的段落（默认） |
| 覆盖未批准 | 覆盖所有未审批通过的段落     |
| 覆盖全部   | 覆盖所有段落，无论状态       |

过滤配置可在执行计划中预设默认值，创建作业时按需覆盖。

### 作业状态

| 状态   | 说明                                 |
| ------ | ------------------------------------ |
| 等待中 | 作业已创建，等待执行                 |
| 运行中 | 正在进行翻译                         |
| 已暂停 | 被手动暂停，可随时恢复（见下方）     |
| 已完成 | 翻译完成                             |
| 失败   | 翻译失败，可查看错误信息或重试       |
| 已取消 | 用户手动取消的作业                   |

### 暂停与恢复

任务列表和任务详情抽屉中提供 **暂停** / **恢复** 操作：

- **暂停**（等待中、运行中可用）— 优雅暂停：停止派发新批次，等待在途请求完成后冻结任务。运行中的任务需要等在途 LLM 请求收尾，界面短暂仍显示「运行中」属正常现象；等待中的任务立即变为「已暂停」
- **恢复**（已暂停可用）— 从轮次断点继续：已完成的轮次与段落直接跳过，进度计数保留，不会从头重跑
- 暂停不会清零进度——界面保留已完成的工作量百分比，并显示「已暂停，可随时恢复」
- 已暂停的任务仍可**取消**；暂停与取消互不替代：暂停是可恢复的中断，取消是终态（但失败/取消的任务也能通过「重试」从断点继续）

::: info 什么场景适合暂停
LLM 速率限额即将耗尽、需要临时让出本机资源、或想在夜间低谷再继续——暂停让任务停在轮次断点，恢复后从同一位置继续，已产出译文不受影响。
:::

### 进度追踪

翻译过程中通过 SSE 实时推送进度信息（支持断线重连、事件持久化）：

- **翻译进度** — 已完成工作量 / 总工作量（单位为「段 × 轮」，见下方「进度口径」）
- **预计剩余时间 (ETA)**
- **当前翻译速度**
- **事件序号（seq）** — 保证事件顺序，重连后可精准恢复丢失的事件

#### 进度口径：工作量而非段落数

主进度按「工作量」统计：分母是已启动轮次的工作量总和（每轮 × 该轮段落数），分子是已完成部分。两点推论：

- **新轮次启动时百分比可能暂时回落**——分母只计入已经启动并得知规模的轮次，后续轮次启动会扩大分母
- **失败、取消、暂停的任务仍显示停下时的真实比例**，不会归零或冻结在旧值
- 任务详情中**失败 / 警告计数按资源数统计，跳过计数按段落数统计**，与「段 × 轮」的工作量口径不同

#### 任务详情：执行概览与事件日志

任务详情抽屉分为**执行概览**与**事件日志**两个标签页：

- **进度卡** — 汇总当前进度、工作量与预计剩余时间；未完成任务会把各轮次铺成可展开的流水线（收起时显示「轮 N / M」摘要），按状态着色，方便定位任务停在哪个环节
- **资源轮次表** — 每个资源一行，展开可查看该资源的逐轮明细：轮次模式（翻译、语义质检等）、各状态计数、轮次序号、段落数、起止时间与错误信息；被暂停 / 停止 / 未执行的轮次有对应的状态图标，收起时汇总展示各资源的轮次完成情况（如「完成 3 轮 · 跳过 1 轮」）
- **更多信息** — 创建 / 更新时间等元数据折叠展示，错误信息会直接显示在概览顶部

作业详情中的 **事件日志** 会把这些事件按 `seq` 顺序铺成一条可滚动的时间线：

- **历史 / 实时分离** — 打开已结束的任务时加载历史记录，可点 **加载更早记录** 向前翻页；任务运行中则通过 SSE 实时追加新事件，离开当前视野的新事件会汇总为「查看 N 条新记录」按钮，连接断开时显示「未连接」
- **异常筛选** — 「全部 / 异常」一键过滤失败、警告等异常记录（仅作用于已加载的记录），排错时不必在正常事件里翻找
- **批次事件卡** — 每个批次翻译事件以卡片形式展示状态与摘要，**点击卡片** 打开右侧 **批次详情抽屉**
- **批次详情抽屉** — 展示该批次的完整元数据：状态、错误信息、发送 / 接收内容、术语使用情况，以及截断 / 解析修复诊断标签（见 [翻译审校 · 截断与修复诊断](/zh/guide/review#截断与修复诊断)），便于排错与复盘
- **跳过状态** — 因目标段状态不满足 `segment_filter` 而未执行的批次，会标记为 `skipped`（信息色），与成功 / 部分成功 / 失败区分
- **清空当前日志** — 一键清空已加载的事件记录

::: tip 历史事件也可查询
任务事件不仅能在界面里看，也有对应的 REST 分页端点（按 `seq` 游标双向翻页），便于外部监控或导出。详见 [API 概述 · 任务事件](/zh/api/#_9-任务事件历史-分页)。
:::

### 作业操作

- **暂停 / 恢复** — 见上方「暂停与恢复」
- **取消** — 取消等待中、运行中或已暂停的作业（终态）
- **重试** — 对失败或已取消的作业重新执行：失败/取消的资源重新入队，已完成轮次与已翻译段落直接跳过，从当前进度断点继续。例外：显式手选段落的任务，首个翻译轮会重译所有选中段落

::: tip 服务重启不用重来
服务升级或重启时，运行中的任务会在下次启动时自动恢复执行，已完成的轮次与译文保留；也可以在任务中心或详情抽屉手动 **重试**。
:::

## 任务中心（跨项目任务列表）

顶栏的 **任务中心** 把你有权限查看的翻译、术语同步与**文件存储**任务（文件上传 / 源文件更新 / 同字节修复）**跨项目**汇总在一页：支持按任务类型、状态、项目、触发来源与更新时间区间过滤，点击条目直接打开对应任务详情（含取消 / 重试 / 暂停 / 恢复操作）。文件存储任务的阶段与清理状态说明见 [存储管理 · 存储任务](/zh/guide/storage#存储任务)。

- 任务可见性跟随项目读权限；服务器模式下，同组织成员可以看到同一项目内其他成员创建的任务
- 状态汇总卡片展示各状态任务数与近 7 天失败数
- 长任务不必停在项目页——页头的 **当前任务** 按钮弹出追踪面板，显示活动任务数与「失败提醒 / 需要处理 / 等待自动重试」计数，可清除已结束任务、隐藏提醒，空闲时只留图标

::: info 操作前会保护未保存内容
有未保存的译文或备注时发起源文件更新等操作，会先弹出保存确认；登录态或归属变化后操作会被拦截，结果未知时引导查看原任务，避免重复提交。详见 [存储管理 · 会话与草稿保护](/zh/guide/storage#会话与草稿保护)。
:::

将术语表关联到项目，翻译时自动应用术语规则。启用后，翻译引擎会优先使用术语表中的翻译结果。

## 项目删除

删除项目时会**级联删除**以下所有关联数据：

- 翻译作业及其关联关系
- 资源文件及其段落
- 术语表条目
- 翻译记忆条目
- 同步任务记录
