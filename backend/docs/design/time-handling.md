# 统一时间存储与接口约定

平台记录的是时间点，与服务器或用户所在时区无关。后端采用 UTC，浏览器负责将时间点显示为用户本地时间；不需要为每个用户保存一份不同的数据库时间。

## 存储与精度

- 所有生产 ent 客户端和测试客户端通过 `database.NewDriver` 编码时间参数，包括写入、查询、批量操作、`Tx` 和 `BeginTx`。SQLite 时间列继续使用 `datetime`，值固定为 `2006-01-02T15:04:05.000000000Z`，保证文本索引与真实时间顺序一致。
- PostgreSQL 保持原生 `timestamptz`，精度为微秒，所有池连接及读回时间使用 UTC。SQLite 保留纳秒。SQL 列直接参与比较和排序，不通过字符串解析函数转换。
- SQLite DSN 不得包含 `_time_format`、`_time_integer_format`、`_timezone`、`_inttotime` 或 `_texttotime`，即使值为空或显式指定 UTC 也会报配置错误。其他连接选项继续沿用原行为。
- `timeutil` 用于平台时间点、DTO 和时间默认值。耗时、限流、超时及重试逻辑继续使用 Go 单调时钟；不要将所有 `time.Now()` 机械替换为 UTC 工具。
- 用户正文、任意 metadata 和导入文档中看似日期的值不做转换。QA 的 `DecidedAt` 属于平台字段，JSON 编解码统一 UTC；冲突检测按实际时间点比较。

## 旧 SQLite 与启动检查

本期没有旧时间格式转换器，也不自动删除、重写或回填旧数据库。升级前停止旧进程，保留原数据库及其 WAL/SHM 配套文件或完整数据目录；需要备份时在服务完全停止后复制完整目录。

使用新的 `data_dir`，或将 `server.database.dsn` 指向新的 SQLite 文件，并以 `auto_migrate=true` 首次启动。新路径会创建空库，原有账号、项目、资源和任务不会自动出现在新库中；需要继续访问旧数据时保留旧版本及原配置。本期没有历史导入工具。

启动检查发生在 ent 建表、本地用户/管理员初始化及服务监听之前：

| 数据库状态 | 行为 |
| --- | --- |
| `user_version=0` 且没有用户 schema 对象 | `auto_migrate=true` 时在短 `BEGIN IMMEDIATE` 事务中检查并标记为 `1`，提交后由 ent 建表 |
| `user_version=0` 且存在用户 schema 对象 | 视为旧格式，拒绝启动，提示保留旧库并配置新路径 |
| `user_version=1` | 按当前统一格式打开；正常 schema 变更仍沿用 ent 迁移 |
| 其他版本 | 拒绝启动，防止误读未知格式 |
| `auto_migrate=false` 且格式未初始化或缺少所需表/列 | 明确报错；不标记或补建数据库 |

`user_version` 只标识编码约定，不保证 schema 初始化成功；建表失败可以在开启自动迁移后重试。不得手工给旧库设置版本标记以跳过检查。此检查读取 schema 元数据，不扫描业务记录。PostgreSQL 已有数据继续使用，无需重建。

## API、SSE 与统计

- 输入接受带时区偏移的 RFC3339，例如 `2026-09-29T12:00:00.123456789+08:00`；对应的 UTC 输出为 `2026-09-29T04:00:00.123456789Z`。响应使用 RFC3339Nano：小数秒按有效位数输出，没有小数时可省略。
- 可空时间继续返回 `null` 或遵循字段原有省略规则。日志审计、字符串 DTO、生成 DTO、SSE 实时/重放/历史采用一致 UTC 口径。
- SSE 在持久化、加入内存重放和广播之前对齐对应数据库的精度，PostgreSQL 使用微秒；即使持久化失败降级广播，也保持相同口径。
- JWT 响应到期时间与实际 `exp` 相同；刷新令牌使用数据库实际存储的到期值。TTL 与认证规则保持原样。
- 任务更新时间过滤为 `[updated_from, updated_before)`。对于 PostgreSQL 微秒刻度，两个边界均向上对齐到下一个可表示微秒，保持原始输入区间匹配的记录集合；游标必须使用数据库读回时间，超过数据库精度的游标返回 400。
- 最近失败数统计当前状态为 `failed` 且更新时间处于 `[as_of - 168h, as_of)` 的任务，和用户自然日、夏令时无关。活动数量不受该窗口限制。

## 验证

测试覆盖 UTC/正负偏移/夏令时、服务器时区变化、固定小数秒、空值、事务与批量操作、索引查询、并发格式初始化、旧库保护、建表重试、QA 撤销与预览冲突、SSE 路径和令牌到期时间。任务权限、分页、控制及历史事件继续运行原有回归。

运行 `task backend:format`、`task backend:lint`、`task backend:test`、`task backend:test:race`。PostgreSQL 集成使用专用测试库，通过 `LINGUAFLOW_TEST_POSTGRES_DSN` 配置；未配置时测试会明确跳过，不能将其视为真实 PostgreSQL 验证通过。
